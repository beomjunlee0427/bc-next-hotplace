## 2. 데이터 개요

### 분석 단위

한 행은 다음 조합으로 구성됩니다.

`월 × 시도 × 시군구 × 성별 × 연령대 × 업종코드`

이 분석 단위에서 중복 행은 **0건**으로 확인되었습니다.

### 기간별 행 수

| 월 | 행 수 |
|---|---:|
| 2026-01 | 40,267 |
| 2026-02 | 40,160 |
| 2026-03 | 40,433 |
| 2026-04 | 40,507 |
| 2026-05 | 40,696 |
| 2026-06 | 40,511 |

월별 행 수는 약 4만 건 수준으로 큰 편차가 없습니다.

## 3. 수행한 전처리

| 단계 | 처리 내용 | 목적 |
|---|---|---|
| 컬럼 검증 | 필수 9개 컬럼 존재 여부 확인 | 입력 구조 오류 조기 발견 |
| 문자열 정리 | 문자열 컬럼 양끝 공백 제거 | 동일 값의 불필요한 분리 방지 |
| 업종명 정리 | 업종명 내부 공백 제거 | `편 의 점`과 같은 표기 통일 |
| 날짜 변환 | `STRD_YYMM`을 `YYYY-MM` 형식으로 변환 | 월별 분석 가능하게 정리 |
| 수치 변환 | `amt`, `cnt`를 정수형으로 변환 | 산술 연산과 검증 가능하게 정리 |
| 값 검증 | 결측, 숫자 변환 실패, 0 이하 값 확인 | 비정상 수치 차단 |
| 중복 검증 | 분석 단위 기준 중복 확인 | 중복 집계 방지 |
| 코드 검증 | 업종코드와 업종명 매핑 확인 | 코드명 불일치 방지 |
| 미상 처리 | 성별·연령 `x`를 원본 그대로 유지 | 정보 손실 방지 |

### 미상값 처리 원칙

`GENDER_CD = x`와 `AGE_CD = x`인 행은 삭제하거나 임의의 성별·연령으로 대체하지 않았습니다.

대신 다음 파생변수를 추가했습니다.

```text
unknown_demo = 성별과 연령이 모두 x인지 여부
```

미상 인구통계 행은 전체의 약 **5.4%**입니다.

## 5. 추가 생성 변수

| 변수 | 설명 |
|---|---|
| `month` | `STRD_YYMM`을 변환한 월 값 (`YYYY-MM`) |
| `unknown_demo` | 성별·연령 미상 여부 |
| `avg_amt_per_cnt` | 행 단위 건당 금액 (`amt / cnt`) |
| `log_amt` | 금액 로그 변환값 (`log(amt + 1)`) |
| `log_cnt` | 건수 로그 변환값 (`log(cnt + 1)`) |

> 지역·업종별 건당 금액을 계산할 때는 행별 평균의 평균이 아니라 `sum(amt) / sum(cnt)`를 사용해야 합니다.

## 8. 해석 시 주의사항

1. 이 데이터는 개인 단위 원천 데이터가 아닌 집계 데이터입니다.
2. `amt`와 `cnt`의 정확한 업무적 정의는 데이터 제공 코드북 확인이 필요합니다.
3. `x` 집단은 미상값이므로 성별·연령별 비교에서 별도 집단으로 보고해야 합니다.
4. 총금액은 지역 규모의 영향을 받으므로 건수와 건당 금액을 함께 비교해야 합니다.
5. 극단값을 바로 제거하기보다 원인 확인 후 로그 변환 또는 분위수 기준으로 분석하는 것이 좋습니다.

## 10. EDA 결과 요약

### 월별 추이

- 총금액은 **2026년 5월**에 약 **3.21조 원**으로 가장 높았습니다.
- 총금액은 **2026년 2월**에 약 **2.67조 원**으로 가장 낮았습니다.
- 5월 총금액은 2월보다 약 **20.3%** 높았습니다.
- 6월 총금액은 전월 대비 **11.5% 감소**했습니다.
- 가중 건당 금액은 2월에 약 **19,267원**으로 가장 높았고, 6월에는 약 **17,238원**으로 가장 낮았습니다.

### 지역별 분포

| 순위 | 시도 | 총금액 비중 | 가중 건당 금액 |
|---:|---|---:|---:|
| 1 | 경기도 | 23.0% | 18,454원 |
| 2 | 서울특별시 | 18.3% | 16,051원 |
| 3 | 부산광역시 | 9.9% | 17,334원 |

경기도와 서울특별시의 합산 총금액 비중은 **41.3%**입니다. 다만 이는 지역 규모의 영향을 받으므로 인구·사업체 수 등의 보정 없이 지역 소비성향으로 단정하면 안 됩니다.

### 업종별 분포

| 순위 | 업종 | 총금액 비중 | 가중 건당 금액 |
|---:|---|---:|---:|
| 1 | 일반한식 | 36.9% | 36,633원 |
| 2 | 슈퍼마켓 | 15.8% | 19,011원 |
| 3 | 편의점 | 14.4% | 8,117원 |
| 4 | 서양음식 | 11.1% | 10,965원 |

일반한식은 총금액 비중이 가장 크지만, 건당 금액 기준으로는 일식회집·한정식·갈비전문점 등 표본 규모가 작은 업종이 더 높게 나타납니다. 따라서 업종 비교 시 총금액과 건당 금액을 함께 봐야 합니다.

### 인구통계별 분포

- 총금액 기준 상위 조합은 `GENDER_CD=1, AGE_CD=5`와 `GENDER_CD=1, AGE_CD=6`입니다.

- 미상 집단을 제외한 분석과 포함한 분석을 모두 비교하는 것이 좋습니다.
